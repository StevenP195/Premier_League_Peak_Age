# When Do Premier League Players Peak?

A two-page static site asking one question of Premier League data: at what
age do players actually peak, and how does that compare to when clubs pay
the most for them? `index.html` is a scrollable report with nine findings
plus a conclusion; `dashboard.html` is an interactive explorer over 149,637
player-match rows. Built from Transfermarkt, FBref, and SoFIFA/EA Sports FC
data (all via Kaggle).

## Files

### Pages
- `index.html` &mdash; the report: a title/summary, four headline numbers,
  nine data-backed findings (each with a chart or the interactive XI), a
  conclusion tying the findings back to the original question, and a closing
  section on where the data comes from and how every number is computed.
- `dashboard.html` &mdash; the interactive dashboard: four filters (season,
  club, position, age group), four summary numbers, four charts each with a
  measure switch and a breakdown switch, a tabbed table showing the numbers
  behind any of the four charts, and a reset-filters button.

### Styling
- `css/style.css` &mdash; all styling for both pages: the shared nav bar,
  color system (the Premier League gradient and club-color theming), stat
  tiles, chart cards, the formation pitch, and the dashboard's filter/table
  controls.

### Scripts (loaded by the browser)
- `js/club-colors.js` &mdash; shared lookup tables (club &rarr; primary/secondary
  color, club &rarr; crest filename) used by both the dashboard and the report's
  Player XI.
- `js/report.js` &mdash; fetches `data/report_findings.json` and renders every
  chart and headline number on the report page.
- `js/squad-xi.js` &mdash; fetches `data/squad_xi.json` and drives the
  interactive 4-3-3 Player XI (age slider, team filter, hover tooltips,
  summary tiles).
- `js/dashboard.js` &mdash; loads `data/player_match.csv` in the browser and
  implements all dashboard filtering, aggregation, charting, club theming,
  and the tabbed table.

### Data (derived; not hand-edited)
- `data/player_match.csv` &mdash; one row per player per Premier League match
  appearance (149,637 rows); the dashboard's raw data source.
- `data/player_season_summary.csv` &mdash; one row per player per season,
  aggregated from the match data and enriched with FBref advanced stats and
  FIFA ratings; used to build the report's findings.
- `data/report_findings.json` &mdash; precomputed chart series and summary
  statistics for the report page, generated by `scripts/analysis.py`.
- `data/squad_xi.json` &mdash; the highest-valued player at each formation
  slot for each age, league-wide and per club, generated by
  `scripts/build_squad_xi.py`.

### Scripts (data pipeline; run with Python, not by the browser)
- `scripts/build_data.py` &mdash; reads the raw Transfermarkt/FBref/FIFA
  exports and produces `player_match.csv` and `player_season_summary.csv`.
- `scripts/analysis.py` &mdash; reads `player_season_summary.csv` and the raw
  valuations, computes every age-curve finding and summary statistic, and
  writes `report_findings.json`.
- `scripts/build_squad_xi.py` &mdash; reads the raw players/valuations data
  and writes `squad_xi.json`.

### Assets
- `assets/pl-badge.png` &mdash; the Premier League badge shown in the
  report's top-right corner.
- `assets/crests/*.png` &mdash; 39 club crest images (one per Premier League
  or Championship club appearing in the data, e.g. `arsenal-fc.png`,
  `chelsea-fc.png`, `manchester-city.png`), shown on the dashboard's club
  badge and as the player-dot color/icon source for the Player XI.

## Data sources

- Transfermarkt (via Kaggle): match appearances, player bios, market valuations
- FBref (via Kaggle): pass completion, take-ons, aerial duels, tackles, GK save/clean-sheet rates
- SoFIFA / EA Sports FC ratings (via Kaggle): overall, potential, pace

See the "About this data" section on the report page for row definitions, exclusions, and how every rate is computed.

## Running locally

```
python -m http.server 8000
```

then open `http://localhost:8000/index.html`.
